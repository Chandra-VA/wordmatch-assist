# WordMatchAssist · 极速配词助手

Android 双语词卡配对实验项目：通过无障碍节点读取、词库匹配和状态确认，在授权的练习场景中提供配对提示、学习记录与自动操作。

**公开源码的研究项目，原创部分保留权利，非 Duolingo 官方产品。** 自动点击、暂停操作和学习材料处理可能涉及平台规则、账号限制及内容权利。仓库公开与否及免责声明均不代表获得平台许可；使用前阅读 [使用边界](DISCLAIMER.md)、[隐私说明](PRIVACY.md) 和 [安全政策](SECURITY.md)。不要用于考试代答、刷榜或规避服务限制。

## 功能

| 模式 | 行为 | 数据与权限 |
| --- | --- | --- |
| 学习模式 | 观察手动配对，确认完成后保存词对并高亮 | 无障碍服务；本机词库 |
| 自动模式 | 本地精确匹配、连续确认、有限恢复；最后一对可直接配对，未知词可启用 AI 补全 | 无障碍读取、点击与返回操作；可选屏幕共享和 HTTPS 模型请求 |

配对器不是服务器答案接口。高亮和 AI 推断都可能出错；界面版本、节点暴露、动画、旋转和语言变化可能导致停顿或误判。单元测试不能替代真机验证。

**自动加速**：Android 11+ 启动自动模式时按系统提示共享整个屏幕。每帧只读取目标词卡的少量背景像素，丢弃切换词对后的首帧并复核连续绿卡反馈，再验证当前页面与词卡位置后继续。拒绝或停止共享仍会自动答题；通过节点和可用的无障碍截图确认。切换到学习模式或关闭辅助会停止连续画面捕获。实际速度仍受设备与动画影响，尚未真机测速。

已授权不代表共享会一直保持。Android 在另一项屏幕捕获启动等情况下可能结束旧共享，详见 [Android 的屏幕共享生命周期说明](https://developer.android.com/media/grow/media-projection#resource_recovery)。若提示“共享已中断”，回到助手重新选择自动模式并授权可恢复；录屏也可能再次触发中断，具体取决于系统实现。

**大模型补词**：默认关闭。开启后在处理已知词时后台补全未知词，等到只能处理未知词时才暂停等待。取消会中断连接，超时约束覆盖整次请求；验证屏幕原词、一对一和有限置信度，写入成功后才用于匹配。设置页可用乱序两对示例测试返回数量和耗时。受控响应单元测试不能证明手机上配置的密钥、模型及网络已可用。

**固定高亮**：每个当前词对第一次被识别时分配颜色和编号，其他词消除、词卡换位或暂停恢复都不重新编号；标记随对应卡片消失，新词对使用空出的编号。同文字重复卡按位置区分。

**卡住恢复**：单边选中时只补点搭档；双方仍为白底深色文字时转入重新检查。已完成灰卡、绿卡或不确定画面不能触发补点。确认仍可点后只解除这一对的旧记录，最多补试两次；再次核对页面、文字与位置，证据不足时交给用户接管。

## 快速构建

需要 JDK 17、Android SDK Platform 36 / Build Tools 36.0.0；最低运行版本为 Android 6.0（API 23）。Gradle Wrapper 固定为 9.5.0，Android Gradle Plugin 固定为 9.3.0。

```sh
git clone https://github.com/Chandra-VA/wordmatch-assist.git
cd wordmatch-assist
./gradlew :app:testDebugUnitTest :app:assembleDebug
```

Windows PowerShell 使用 `./gradlew.bat`。将 Android SDK 路径通过 `ANDROID_HOME` 或本机 `local.properties` 的 `sdk.dir` 设置；首次构建需要网络下载工具和依赖。当前仓库可公开读取；公开可见不等于授予开源许可。

Debug 安装包生成于 `app/build/outputs/apk/debug/app-debug.apk`。它使用开发者自己的 Debug 签名，不能保证覆盖其他人签名的安装包。

```sh
# 没有私有签名配置时生成 unsigned Release，不会偷偷使用 Debug 密钥
./gradlew :app:assembleRelease
```

Release 签名、代理及可选镜像配置见 [构建指南](docs/BUILDING.md)。仓库不包含 APK、历史安装包、本机 SDK/JDK、API 密钥、私钥或个人词库。不要为安装开发版本而直接删除重要学习记录；先了解签名差异和数据保留方式。

## 使用

1. 首先阅读权限和数据说明；在自己的设备及获许可的练习场景中使用。
2. 打开应用选择学习模式，在 Android 无障碍设置中启用服务。自动模式会实际点击并操作暂停确认框，需单独选择。
3. 进入兼容的配对题。悬浮球可切换学习/自动模式或关闭辅助；发生误判时立即关闭自动。
4. 内置词表只是通用入门示例。导入自己有权使用的 UTF-8 词对文件，格式如 `apple,苹果`；逗号、分号或制表符分隔。不附带完整课程题库。
5. AI 补词默认关闭，按需配置 HTTPS Chat Completions 地址与模型。测试按钮也会发起请求；域名或端口改变后需重新输入对应密钥，或先清除旧密钥。
6. 自动模式共享画面只用于本机颜色确认，不保存、不上传。捕获范围由系统授权决定，可能包含其他应用和通知，可随时通过系统停止共享。节点不可读的页面无法自动配对。

模型名称、收费及接口可用性由提供商决定。不要把“高置信”理解为答案保证，也不要把“本地识别”理解为整个应用完全不联网。

## 项目结构

```text
app/src/main/java/com/wordmatch/assist/
  accessibility/  节点扫描、页面判断、自动操作状态机
  matching/       词库、配对、尾对及失败恢复策略
  learning/       手动配对确认与学习
  ai/             可选接口、响应验证、密钥和传输保护
  capture/        自动模式的连续词卡颜色确认
  overlay/        配对高亮与模式控制
app/src/test/     JVM 回归测试
scripts/          上传内容检查
.github/          CI、依赖更新和协作模板
```

设计说明见 [架构](docs/ARCHITECTURE.md)，变化记录见 [CHANGELOG](CHANGELOG.md)。
